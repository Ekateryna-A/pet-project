## 🏷️ Модуль 2: МАРКЕТИНГОВАЯ ЛОГИКА И РАСЧЕТ СКИДОК

### ✅ Позитивные проверки

**📈 Активация скидки и пересчет цен:**
* ✅ `DIS-1` [Добавление в корзину 5 тортов строго из каталога](#) - Итоговая стоимость рассчитывается со скидкой 10% на все товары.
* ✅ `DIS-2` [Добавление в корзину 5 тортов из каталога и 1 торта из конструктора](#) - Дисконт 10% применяется только к сумме товаров из каталога; стоимость торта из конструктора остается неизменной.
* ✅ `DIS-3` [Динамический пересчет итоговой суммы при изменении состава корзины](#) - Сумма пересчитывается в режиме реального времени при добавлении/удалении позиций.
* ✅ `DIS-4` [Визуальное отображение активации скидки в интерфейсе](#) - В корзине корректно отображается старая (зачеркнутая) и новая цена со скидкой.

### ❌ Негативные проверки

**⚠️ Проверка ограничений и блокировок маркетингового движка:**
* ✅ `DIS-5` [Добавление в корзину 4 тортов из каталога (нехватка объема)](#) - Расчет стоимости происходит по стандартному тарифу, скидка не активируется.
* ✅ `DIS-6` [Проверка смешанной корзины при невыполнении условий (4 из каталога + 1 из конструктора)](#) - Общее число позиций равно 5, но расчет идет без скидки, так как счетчик проверяет строго тип товара из каталога.
* ✅ `DIS-7` [Добавление в корзину 5 тортов только из кастомного конструктора](#) - Расчет стоимости происходит без учета скидки, так как конструктор полностью исключен из акции.

### 🧩 Расчет смешанной корзины при достижении лимита товаров

`ID: DIS-001` &nbsp;&nbsp;|&nbsp;&nbsp; `Приоритет: High` &nbsp;&nbsp;|&nbsp;&nbsp; `Статус: PASS` ✅

**💻 Окружение:** `Yandex Browser` (v 26.6.4), `OS Windows 10`

**📋 Предусловия:**
1. Пользователь авторизован в системе.
2. В корзине применимо правило: Скидка 10% действует только на позиции из каталога при условии наличия от 5 штук. На торты из конструктора скидка не распространяется.
3. Стоимость любого торта из каталога в тесте = 1000 руб.
4. Стоимость торта из конструктора в тесте = 1500 руб.

**🚀 Шаги воспроизведения:**
1. Перейти в каталог и добавить в корзину 4 торта.
2. Перейти в конструктор, собрать кастомный торт и добавить его в корзину.
3. Перейти в корзину и проверить итоговую сумму заказа.
4. Вернуться в каталог и добавить в корзину еще один торт.
5. Проверить финальную стоимость в корзине.

**🎯 Ожидаемый результат:**
* **На шаге 3:** Общая сумма заказа составляет 5500 руб. (4000 руб. за каталог + 1500 руб. за конструктор). Скидка отсутствует.
* **На шаге 5:** К 5 тортам из каталога применяется скидка 10% (их стоимость уменьшается с 5000 руб. до 4500 руб.). Торт из конструктора считается по полной стоимости (1500 руб.). Финальная сумма составляет ровно 6000 руб. Рядом отображается информационная плашка: *«Применена скидка 10% на товары из каталога»*.
