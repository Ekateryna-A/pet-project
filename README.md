# 📂 Комплексный практикум по QA-тестированию 

> **📁 Описание репозитория:** Добро пожаловать в мое практическое QA-портфолио! Этот репозиторий создан для демонстрации моих навыков тест-анализа, тест-дизайна и работы с техническим стеком. Портфолио разделено на два принципиально разных блока: концептуальное моделирование тестовой документации с нуля и исследовательское тестирование реального боевого API.

---

## 🗺️ Навигационная карта проектов

### 🍰 Блок 1. Моделирование ручного тестирования платформы «ТортИзи» (Симуляция)
*Этот проект полностью спроектирован в моей голове. Самого сервиса кастомных тортов не существует в реальности, но на его примере я продемонстрировала, как умею выстраивать тестовые процессы на бумаге с самого нуля, начиная от анализа сырых требований заказчика до составления интерактивных чек-листов и баг-репортов.*
* ➔ [👉 Перейти к материалам Блока 1: «ТортИзи»](./1.%20Сервис%20"ТортИзи"%20-%20ручное%20тестирование/1.%20Сырой%20бриф/README.md)

### 🛰️ Блок 2. Исследовательское тестирование REST API NASA NeoWs (Реальный проект)
*В отличие от первого блока, здесь велось тестирование реального, работающего API космического агентства NASA в Postman. В условиях полного отсутствия спецификации мне удалось провести глубокий анализ вложенных JSON-структур, спроектировать полноценную тестовую коллекцию и обнаружить реальные архитектурные аномалии парсинга URL-строки при работе с кодировками.*
* ➔ [👉 Перейти к Обложке Блока 2: «API NASA»](./2.%20API%20NASA%20NeoWs%20-%20Тестирование%20API%20(Почтальон)/README.md)

### 💻 Мой технический багаж:
* **Инструменты:** `Postman`, `Chrome/Yandex DevTools` (`Network`, `Console`).
* **Тест-дизайн:** Классы эквивалентности, граничные значения, составление чек-листов, тест-кейсов и баг-репортов.
