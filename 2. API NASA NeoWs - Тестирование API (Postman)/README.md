# 🛰️ Тестирование API: NASA NeoWs (Near Earth Object Web Service)

> **📁 Контекст проекта:** В данном модуле представлено комплексное тестирование открытого REST API NASA, предназначенного для мониторинга околоземных астероидов. Проект демонстрирует навыки работы со сложной вложенной JSON-структурой, валидации параметров запросов и глубокого анализа бэкенда без готовой спецификации.

---

### 🛠️ Технологический стек и инструменты:
* **Инструмент тестирования:** `Postman` 
* **Формат данных:** `JSON` 
* **Методы запросов:** `GET`
* **Авторизация:** Протокол авторизации по статическому токену `api_key`

---

## ☄️ Структура тестового покрытия

В ходе проекта были полностью протестированы два ключевых эндпоинта системы. Все запросы разнесены по соответствующим коллекциям в Postman:

### 1️⃣ [GET /feed — Лента астероидов за период](./1.%20Эндпоинт%20Feed%20(Лента%20астероидов)/README.md)
*Тестирование логики работы с диапазонами дат, лимитами выборок (до 7 дней), дефолтными значениями параметров и проверка скрытых алгоритмов автоисправления ошибок на стороне бэкенда.*

### 2️⃣ [GET /lookup — Поиск астероида по ID](./2.%20Эндпоинт%20Lookup%20(Поиск%20астероида)/README.md)
*Валидация поиска конкретных космических объектов по их уникальному системному идентификатору, тестирование граничных значений, обработка спецсимволов и пустых значений.*

---

## ⚙️ Инструкция по запуску коллекции тестов в Postman

Для проверки спроектированных тест-кейсов и логики валидации вы можете запустить импортированную коллекцию локально:

1. Скачайте файл коллекции [NASA_NeoWs_API_Tests.postman_collection.json](./NASA%20NeoWs.postman_collection.json) из данного раздела.
2. Откройте Postman и выполните импорт файла через кнопку **Import** в интерфейсе программы.
3. [Сгенерируйте свой бесплатный персональный токен доступа на официальном портале NASA API](https://nasa.gov).
4. Создайте переменную коллекции или переменную окружения (Environment) с именем `api_key` и вставьте ваш полученный токен в поле *Current Value*.
5. Запустите проверку сценариев через инструмент коллективного прогона (**Collection Runner**).
